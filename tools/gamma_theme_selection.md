# Gamma Theme Selection - Airport Media

Selected base theme: `Gold Leaf`

- Theme ID: `gold-leaf`
- Type: standard
- Why selected: strongest match for a light, rich, premium airport-media sales look.
- Color direction from Gamma: gold, champagne, ivory, white, cream, light beige, soft metallic.
- Tone direction from Gamma: classy, formal, elegant, professional, minimalist, clean, subtle, soft, luxury, mature.

Runner-up themes:

- `editoria` - excellent editorial/professional look; better if we want neutral magazine style over luxury.
- `chimney-smoke` - clean corporate light gray/silver; safer but less rich.
- `gleam` - premium gray/silver tech-professional; good for dashboard/business decks.
- `howlite` - high-contrast light luxury; sharper and more formal.
- `consultant` - very safe consulting/business look; less distinctive.

Reusable base configs:

- `tools/gamma_deck_configs/_base_light_rich_webpage_ai.json`
- `tools/gamma_deck_configs/_base_light_rich_presentation_ai.json`

Deck configs should extend one of these base files and only change:

- `promptPath`
- `outputStem`
- specific per-deck overrides if required
