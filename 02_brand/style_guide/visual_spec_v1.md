# Visual Spec v1 — RAJKOT AIRPORT × MUKESH ARTS

> Locked 2026-05-17. Applies to all Gamma decks (A, B, C), the website, and the demo dashboard. Deck and site must look like one product.

---

## 1. Wordmark

**RAJKOT AIRPORT × MUKESH ARTS** — draft co-brand pending final.

- Cover treatment: stacked, with "×" enlarged in Saffron between the two names
- Header treatment: single line, "RAJKOT AIRPORT × MUKESH ARTS" in small caps
- Always keep AAI partnership signal close (footer line: "Authorised Advertising Partner, Rajkot International Airport — AAI")

---

## 2. Palette

| Role | Name | Hex | Use |
|---|---|---|---|
| Primary | Midnight Blue | `#0B1E3F` | Backgrounds, headers, wordmark base |
| Accent | Saffron | `#F59E0B` | CTAs, "×" mark, callouts, key numbers |
| Surface | Off White | `#FAFAF7` | Card backgrounds, body areas |
| Text Dark | Ink | `#0A0A0A` | Body copy on light surfaces |
| Text Light | Cloud | `#E5E7EB` | Body copy on Midnight Blue |
| Divider | Slate | `#334155` | Hairlines, secondary borders |

**Rule:** Saffron is rare and intentional — used for the ONE thing the eye should land on per slide/page. Never two saffron elements competing.

---

## 3. Typography

- **Display / Headers:** Inter Tight (Gamma: pick "Inter" or "Manrope" if Tight unavailable). Weight 700.
- **Body:** Inter. Weight 400 body, 600 for inline emphasis.
- **Numbers / Pricing:** Inter Tabular Numbers, weight 600, Saffron accent on currency.

Type scale (deck): H1 56pt · H2 36pt · H3 24pt · Body 16pt · Caption 12pt.

---

## 4. Layout patterns (reuse across all decks & site)

**P1 — Hero cover**
- Full-bleed photo (airport exterior or interior shot)
- Midnight Blue overlay at 70%
- Wordmark + tagline centered

**P2 — Asset detail (the workhorse)**
- 60/40 split: left = info card on Off White, right = photo
- Left card stack: Unit code (Saffron) → Asset name (H2) → Size · Location · Tech bullets → small inline floor-plan thumbnail
- This mirrors the existing PDF layout the user already approved — buyers' eyes know where to land

**P3 — Inventory grid**
- 3-column card grid, each card: photo + unit code + size + location pill
- Used for "all units in this package at a glance"

**P4 — Comparison table**
- Dark Midnight Blue table, Saffron header row, Cloud text
- Used for package comparison and pricing

**P5 — Floor-plan callout**
- Full-width floor plan with Saffron circles marking units (replaces the existing red/black circles in current PDFs)

**P6 — Closing CTA**
- Midnight Blue full bleed, Saffron CTA button, single contact line

---

## 5. Iconography & photo treatment

- **Icons:** Lucide icon set, outlined, Saffron or Cloud only — never both colors in one icon
- **Photos:** Use the existing on-site photos from `/04_media_kit/assets/` but apply consistent treatment in Gamma:
  - Slight cool tint to unify (the current phone photos have varying warmth)
  - 12px rounded corners
  - Subtle Slate hairline border
- **Floor plans:** Re-circle the unit markers in Saffron, remove the parchment background, place on Off White

---

## 6. Voice on visuals

- One headline thought per slide. If it needs two thoughts, it's two slides.
- Numbers are heroes. "70-80 boards" > "an extensive inventory of digital and static media units."
- Never use the generic airport-clipart cover from the existing PDFs again.

---

## 7. Do / Don't

| Do | Don't |
|---|---|
| Lead with the unit code in Saffron | Hide the unit code in body text |
| Show floor-plan + on-site photo together | Show one without the other |
| Quote ₹ amounts in tabular numerals | Round or fudge real pricing |
| Use real on-site photos | Use stock airport clipart anywhere |
| Footer the AAI partnership line | Make AAI the headline (we're the operator, not them) |
