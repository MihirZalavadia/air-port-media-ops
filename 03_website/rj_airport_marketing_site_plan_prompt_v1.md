# RJ Airport Marketing Website Plan Prompt V1

Use this prompt to generate or refine the current Rajkot airport OOH website draft in an AI builder or coding assistant.

---

## Role

Act as a senior product designer, premium B2B website strategist, and frontend engineer. Build a polished starter website for an airport out-of-home advertising business at Rajkot International Airport.

The goal is not a generic marketing landing page. The goal is a strong website draft that can be shown to founders and partners to confirm brand direction, UI quality, buyer flow, inventory presentation, and future CRM potential.

## Brand Context

Public-facing brand should be neutral and marketable:

- Recommended primary name: **RJ Airport Marketing**
- Alternate name options to show:
  - Rajkot Airport Media
  - RAM Airport Media
  - Rangilu Rajkot Airport Media

Do not make Mukesh Arts the public-facing website brand. Owner-side names can appear only in a restrained POC/contact section.

Owner-side POCs:

- Mukesh Patel — Founder / Owner
- Mayur Patel — Managing Partner
- Ridham Bhuva — Airport ASCO & Partner

## Core Business Positioning

Position the business as a premium airport OOH media network for brands that want Saurashtra's travelling audience and high-context airport visibility.

Use confirmed airport stats:

- 1.25-1.30 lakh passenger visits per month
- 4,200-4,400 passenger visits per day
- 14 arrivals + 14 departures = 28 daily flight movements
- Wide airport media inventory starting from INR 2,00,000/month

Do not show detailed public package pricing on every inventory card. Say pricing and final commercials are shared after campaign window, availability, and buyer intent are confirmed.

## Visual Direction

Create a premium airport OOH website, not a playful SaaS dashboard.

Design mood:

- Traditional-classy, modern, premium, trustworthy
- Airport, public movement, digital screens, front-lit boards, runway, travel, brand visibility
- Inspired by high-end portfolio/work pages like Mindbuild style: large visual work cards, editorial spacing, strong image-led inventory presentation
- Avoid generic random business/green-energy/architecture images
- Avoid silly blue-white startup styling
- Avoid a one-note palette
- Avoid public rate-card look

Include two main theme modes:

- **Sunny Takeoff**: bright airport daylight, ivory, sky, brass, deep green
- **Night Runway**: dark runway, amber lighting, charcoal, premium nighttime airport mood

Also include palette options:

- Executive Ivory
- Saurashtra Premium

## Logo Direction

Show 2-3 logo concepts in the first half of the page:

1. **RJ Airport Marketing**
   - Compact RJ mark
   - Runway/takeoff line through or under the mark
   - Best for modern website header

2. **Rajkot Airport Media / RAM**
   - RAM monogram
   - Formal B2B media-kit feel

3. **Rangilu Rajkot Media Route**
   - Restrained local Rajkot color accent
   - Airport route geometry
   - Should feel premium, not festival-like

## Page Flow

Build this as one strong starter website draft:

1. Sticky premium header
   - Logo
   - Navigation: Identity, Why Airport, Inventory, CRM Layer
   - CTA: Unlock Inventory

2. Hero section
   - Full-bleed airport / runway / flight image background
   - H1: RJ Airport Marketing
   - Copy: premium airport media for Saurashtra's travelling audience
   - Day/night theme switch
   - CTA buttons: Preview Inventory Gate, Compare Logos
   - Stat strip: monthly passengers, daily passengers, daily movements, starting range

3. Identity section
   - Logo options
   - Brand name options
   - Tagline options
   - Color palette cards

4. Why airport OOH section
   - Premium context
   - Right buyer fit
   - Consultative plans
   - Explain why airport visibility is stronger than cluttered outdoor corridors

5. Lead-gated inventory section
   - Public visitors should not immediately see full inventory depth
   - Show a premium collage of inventory previews first
   - Add a form before full inventory:
     - Name
     - Company
     - Phone / WhatsApp
     - Campaign window
     - Inventory interest
   - On submit, unlock the demo inventory board locally
   - Mention this is ready to connect to CRM later

6. Full inventory workboard after unlock
   - Use filter chips:
     - All
     - Digital Packages
     - Static Boards
     - Passenger Journey
     - Custom Plans
   - Use large image-led work cards with overlays that look like digital screens, front-lit boards, or backlit placements
   - Each card should include:
     - Code
     - Category
     - Title
     - Summary
     - Lead line
     - Format
     - Unit count
     - Location
     - Unit references
     - Zone chips

7. Commercial positioning section
   - "Wide airport media inventory, starting from INR 2,00,000/month."
   - Explain that final media kit, availability, and commercials are shared after campaign window and buyer fit are understood

8. POC section
   - Keep it clean and not personal-heavy
   - Show Mukesh Patel, Mayur Patel, Ridham Bhuva with roles and focus
   - Direct contact details TBC

9. Future CRM section
   - Public website now, selected-user CRM in month 2/3
   - Modules:
     - Selected-user CRM for serious leads
     - Inventory maintenance for each plan
     - Owner dashboard for follow-ups and booked value
     - Outreach tracker for right company categories
     - Proposal and media-kit library
     - Campaign value attribution for CRM-originated deals

10. Contact/media kit form
    - Full name
    - Brand/company
    - Phone/WhatsApp
    - Email
    - Campaign window
    - Inventory interest
    - Budget range
    - Message

## Interaction Requirements

- Include a short loading transition: "Loading airport media routes"
- Include day/night theme switch
- Include inventory unlock form behavior
- Include category filter animation
- Keep everything responsive for mobile and desktop
- Make text fit cleanly in cards and buttons
- Do not use nested UI cards
- Do not use oversized decorative blobs/orbs

## Copy Tone

Speak to marketing managers and brand owners. Keep the tone premium, direct, and commercially useful.

Avoid overpromising. Avoid fake official claims. Avoid fake testimonials. Avoid public package rates. Avoid saying final legal/contact/GST details are confirmed if they are not.

## Final Output Expected

Produce a polished responsive website draft that can be shown in a founder meeting to confirm:

- Brand name and logo route
- Color palette
- Website quality
- Inventory browsing style
- Lead-gated buyer flow
- Future CRM value
