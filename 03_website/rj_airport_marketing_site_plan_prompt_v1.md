# Rajkot Airport Media x Mukesh Art Website Prompt V2

Use this prompt to regenerate or refine the current airport OOH website draft in Codex, Claude, Gamma, or another AI builder.

## Objective

Build a premium, first-project-quality airport media website for **Rajkot Airport Media x Mukesh Art**. The page should feel like a polished B2B media-owner product, not a generic SaaS landing page or a raw rate card.

Primary outcome:

- Impress Mukesh Patel, Mayur Patel, and Ridham Bhuva with a serious UI direction.
- Show Rajkot International Airport inventory as a curated media portfolio.
- Qualify serious advertisers before revealing the full inventory board.
- Set up a future CRM / inventory operations layer for month 2/3.

## Brand

Primary public name:

- **Rajkot Airport Media x Mukesh Art**

Use this spelling in the website metadata, loader, hero, header, footer, and pitch copy.

Support names that can appear only as internal alternatives:

- Rajkot Airport Media
- RAM Airport Media
- Rajkot Airport Media Network

Do not use a casual or playful startup identity. The brand should feel corporate, regional, high-trust, and visually rich.

## Visual Direction

Use a light blue airport layer as the dominant web mood:

- Day theme: sky blue, near-white, deep ink, Mukesh red accent.
- Night theme: runway navy, black-blue, soft airport light, Mukesh red accent.
- Keep red rare and intentional: CTA, active states, airport hub, route focus, unit code.

Design motifs:

- Light-blue airport blueprint layer.
- Airplane cutout / flash effect while loading.
- Full-bleed airport and OOH photos.
- Premium portfolio-card inventory grid.
- Image hover zoom, metallic shine, and multi-image gallery fan-out.
- Real India map layer with Rajkot and connected cities marked.
- Floating brand bubbles showing public brand trust.

Avoid:

- Purple SaaS gradients.
- Random non-airport stock photos.
- Cartoon illustrations.
- Fake testimonials.
- Public detailed package prices.
- Overclaiming official/legal status.

## Loader

Create a branded loading splash:

- Light-blue blueprint background.
- Center co-brand mark.
- Text: `Rajkot Airport Media x Mukesh Art`.
- Secondary text: `Preparing airport media view`.
- Airplane SVG/cutout flies across the loader with a red flash.
- Keep animation short and premium, no bounce.
