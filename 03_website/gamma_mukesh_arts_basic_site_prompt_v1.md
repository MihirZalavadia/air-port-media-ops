```
Build a simple one-page website for Mukesh Arts, a Gujarat-based local outdoor and airport media operator.

The site should feel established, straightforward, and trustworthy. It should not feel like a startup pitch deck or a complex sales platform.

Primary goal: create a basic online presence and contact path.

Secondary goal: direct serious airport media buyers to the dedicated Rajkot Airport Media website/page.

Tone:
Humble, factual, local, practical. No overclaiming. No "India's leading" language.

Design:
- Light, clean layout
- Simple typography
- Real photos if available
- Minimal animation
- No complex pricing tables
- No blog
- No CRM-heavy flow
```
