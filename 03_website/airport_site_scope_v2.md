# Airport Website Scope v2 - Main Sales Site

Date: 2026-05-24

## Purpose

This is the primary commercial website for selling media inventory at Rajkot International Airport.

The site should help a brand manager, marketing head, or media planner answer five questions quickly:

1. What can I buy?
2. Where will my campaign appear?
3. What does it cost?
4. Why is this airport audience valuable?
5. Who do I contact to reserve inventory?

## Recommended Build Approach

Start with a high-quality single-page Gamma or static site for speed. Move to Next.js only when we need custom forms, analytics, SEO control, or CRM integration beyond a simple embedded form.

This keeps the pitch moving without turning the website into a software project too early.

## Site Structure

### 1. Hero

Lead with the airport media offer.

Working headline direction:

"Rajkot Airport media inventory for brands that want Saurashtra's premium audience."

Support line:

"Digital screens, static placements, and campaign packages across Rajkot International Airport, operated by Mukesh Arts."

Primary CTA: Request Rate Card

Secondary CTA: View Inventory

### 2. Why Rajkot Airport

Focus on the commercial reason to buy:

- Saurashtra gateway
- NRI and family-business corridor
- Premium dwell time
- High-trust airport environment
- New international airport context

Use only confirmed audience numbers. Keep placeholders out of live pages.

### 3. Inventory Overview

Show the inventory in buyer language:

- Digital LED packages
- Static premium placements
- Trolley media, if ready
- Full-airport bundle

For each package:

- Format
- Surface count
- Location summary
- Monthly rate, if approved for public use
- "Request availability" CTA

### 4. Featured Packages

Feature the strongest packages visually:

- Package 1: 18-unit arrival + SHA horizontal loop
- Package 3: 14-unit vertical display network
- All-digital bundle: 39 digital surfaces

Package 2 and static inventory can stay in the downloadable/requested media kit if the public page becomes too dense.

### 5. Trust and Compliance

Trust signals should be specific:

- Airport media operation at Rajkot International Airport
- AAI partnership/authorisation language after legal confirmation
- ASCO-certified operations through Ridham
- GST-compliant invoicing
- Creative approval and airport protocol handled by the operator

Avoid vague claims like "trusted by leading brands" unless there are approved client names.

### 6. Contact / Lead Capture

Form fields:

- Name
- Brand/company
- Role
- Email
- Phone/WhatsApp
- Campaign window
- Budget range
- Package interest
- Message

CTA copy:

"Request Rate Card"

Response promise:

"We will share current availability and pricing within 1 working day."

## Visual Direction

Keep the existing premium airport palette, but update the brand hierarchy:

- Primary identity: airport media offer
- Supporting line: operated by Mukesh Arts
- Real airport photos over stock imagery
- Pricing and inventory numbers as hero elements
- Sharp, editorial layouts
- No generic SaaS cards or abstract illustrations

## What Not To Build Yet

- Blog
- Login area
- Live booking engine
- Complex animations
- Multi-airport pages
- Automated drip sequences before CRM is ready
- Separate pages for every package

## Success Criteria

The airport website is successful when it can be shown in a pitch and immediately makes the business look sellable, credible, and easy to contact.

Minimum launch standard:

- Looks polished on mobile and desktop
- Uses real airport inventory visuals
- Does not contain unconfirmed stats
- Has one clear CTA path
- Can be sent to an agency buyer without explanation
