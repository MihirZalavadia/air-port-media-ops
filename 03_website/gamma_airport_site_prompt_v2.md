# Gamma Airport Site Prompt v2 - Airport First

> **Status:** Active website direction as of 2026-05-24.
> **Purpose:** Paste-ready prompt for a premium single-page B2B sales website focused on Rajkot International Airport media inventory.
> **Brand rule:** The airport media offer is the main brand. Mukesh Arts appears as operator credibility, not as the hero headline.

---

## GLOBAL DIRECTION

```
Build a premium single-page B2B website for selling advertising inventory at Rajkot International Airport, India.

Audience: brand managers, marketing heads, corporate marketing teams, OOH planners, and ad agencies.

Primary goal: generate qualified inbound inquiries for airport media campaigns.

Brand hierarchy:
- Primary public offer: RAJKOT AIRPORT MEDIA
- Supporting credibility: Operated by Mukesh Arts
- Trust layer: Rajkot International Airport, airport media concession, AAI partnership wording only where legally approved, ASCO-certified operations

Do not make Mukesh Arts the main hero brand. It should appear in the support line, trust section, footer, and contact area.

Voice:
Authoritative, practical, ROI-focused, local pride with national ambition. Boutique airport media operator, not "India's leading." Use specifics over adjectives.

Design:
- Premium airport/editorial feel
- Full-bleed real airport photos wherever possible
- Midnight blue #0B1E3F, saffron #F59E0B, off white #FAFAF7, ink #0A0A0A, cloud #E5E7EB
- Sharp layouts, thin dividers, large pricing/stat typography
- No generic business stock photos
- No abstract SaaS illustrations
- No founder-story-heavy layout

Primary CTA: Request Rate Card
Secondary CTA: View Inventory
```
