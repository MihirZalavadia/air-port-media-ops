## P2 — SEO (directly relevant to the indexing fight)

### 5. All 4 inventory pages declare the HOMEPAGE as canonical ⚠️
`<link rel="canonical" href="https://mukeshart.in/">` on every `/inventory/*` page — they inherit the root layout default because `generateMetadata` in `src/app/(airport)/inventory/[slug]/page.tsx` sets no canonical. This literally tells Google "don't index these, they're the homepage." They're in the sitemap, so Google gets contradictory signals.
**Fix (5 lines):** add `alternates: { canonical: \`/inventory/${slug}/\` }` to `generateMetadata`. While in there, upgrade the thin titles ("Digital Screen Network | Mukesh Art" → "Digital Screen Network at Rajkot Airport | Mukesh Art" etc.) — free keyword surface.
