# Package 3 — The 14-unit Vertical Display

**₹3,00,000/month + GST · 10-sec slot · 2-min cycle**

Portrait-format premium screens. Eight 75" and six 65" verticals — the "human-eye-level" format that performs best for product photography, fashion, jewellery, real estate. Placed in high-dwell pause zones (cafés, lounges, escalator landings) where passengers are stationary.

- Departure Check-in — AD_10 *(both-side, 75")* near SHA entry (Air India + Indigo sides)

- SHA First — AD_23 *(both-side, 75")* near Jet Set Café · AD_24 *(both-side, 75")* near Synergy Health Lounge · AD_44, AD_45, AD_46 *(65")* across gate sitting areas
- Arrival GF — AD_47, AD_48 *(65")* near luggage belt

**Format mix:** 8 × 75" vertical + 6 × 65" vertical = 14 units in the loop.
