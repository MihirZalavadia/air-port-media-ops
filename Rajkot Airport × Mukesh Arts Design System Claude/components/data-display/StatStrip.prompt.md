**StatStrip** — bordered row of big serif figures with mono captions. The airport credibility numbers.

```jsx
<StatStrip onPhoto stats={[
  { value: "1.25–1.30L", label: "Passenger visits / month" },
  { value: "4,200+",     label: "Passenger visits / day" },
  { value: "28",         label: "Daily flight movements" },
  { value: "₹2L+",       label: "Starting inventory range" },
]} />
```

Use `onPhoto` over the hero image; omit it on light bands. Keep figures real and specific.
